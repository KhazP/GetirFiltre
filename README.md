# A Chrome extension for GetirYemek (Turkish food delivery platform) that enables users to ignore/blacklist restaurants and apply advanced custom filters beyond the platform's native capabilities. Users can hide restaurants they dislike (e.g., fast food chains, overly expensive places) and filter by multiple criteria simultaneously (rating + distance + price) to find their ideal restaurants faster.
